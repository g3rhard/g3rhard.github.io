🚀 Welcome to this week’s Friday Readings!

A fresh batch of interesting tools, security research, infrastructure deep dives, and reflections on how AI is changing engineering culture.

## 🛠️ Tools & Projects

* [Portless](https://github.com/vercel-labs/portless) - A Vercel Labs experiment that removes the need to manage ports when running local services. Interesting concept for simplifying local development environments.
* [git-cliff](https://github.com/orhun/git-cliff) - A highly customizable changelog generator that uses conventional commits and templates to produce clean release notes.
* [worldmonitor](https://github.com/koala73/worldmonitor) - A terminal-based global monitoring dashboard showing real-time data like earthquakes, weather, and world statistics.
* [Fizzy](https://github.com/basecamp/fizzy) - A simple event-based messaging system by Basecamp designed to keep things lightweight and understandable.
* [Hapticpad](https://github.com/dmcke5/Hapticpad) - A creative project turning a touchpad into a haptic interface experiment.
* [gptme](https://github.com/gptme/gptme) - A CLI tool that lets you interact with LLMs directly from your terminal and automate workflows with AI.
* [Claude Code Templates](https://github.com/davila7/claude-code-templates) - A collection of templates for building structured Claude-based coding workflows.
* [Claude Code System Prompts](https://github.com/Piebald-AI/claude-code-system-prompts) - A repository documenting and analyzing system prompts used by Claude coding tools.
* [AI Skills Library](https://www.aitmpl.com/skills) - A growing collection of reusable AI prompts and “skills” for different workflows.
